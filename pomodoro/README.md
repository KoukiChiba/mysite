# Pomodoro Timer

参考サイト pomodorotimer.online の構成をもとに、旧 StudyForest を置き換えた静的なポモドーロアプリ。URLパスは `/pomodoro/`。

## 起動

リポジトリのルートで `python3 -m http.server 8080 --directory mysite` を実行し、`http://localhost:8080/pomodoro/` を開く。ビルドやAPIキーは不要。

テスト：`node --test mysite/pomodoro/tests/timer.test.cjs`（リポジトリのルートから）。`tests/mobile-preview.html` は390×700pxの表示確認用。`tests/music-preview.html` は各MP3の末尾を実際に再生し、8曲の自動移行と先頭への戻りを検証する画面。

## 機能

- 集中・小休憩・長い休憩、時間と周期の変更、自動開始、終了音
- 終了予定時刻によるタイマー復元、再読み込み・複数タブへの対応
- タスク・サブタスク、ステータス・優先度・期限・タグ・説明、検索・フィルター、集中時間の記録
- 元サイトと同じLOFIトラック8曲の順次再生（8曲目の後は1曲目）、環境音・音量調整（従来の4曲はファイルとして保持）
- 湯気などが動くローファイ動画背景・城・街などの背景、6色のテーマ・4種類の演出、写真8枚までの保存、暗さ・ぼかし
- 日単位のストリーク・週の記録・累計時間、1日あたりの集中時間チャレンジとごほうび
- Chrome・EdgeのDocument Picture-in-Pictureによる最前面ミニタイマー
- PWA、オフライン利用（初回オンライン読み込み後）
- スペースで開始・一時停止、Rでリセット、Escでパネルを閉じる

下部の機能説明・FAQ・フッターは置かず、タイマー画面だけで利用する。

## 検索エンジン

本体と確認用ページに `noindex, nofollow` を設定。検索結果への登録を抑止するための指定であり、アクセス制限ではない。

## 保存と制約

タスク・設定・記録はlocalStorage、写真はIndexedDBに保存。端末間同期やログインはなし。旧StudyForestの木の育成機能・データ移行はなし。旧保存データは削除しない。

ブラウザを閉じている間・端末スリープ中の終了音は保証されない。再訪時には最後のセッションを一度だけ記録し、次のモードに進む。自動開始はページが動作している間のみ。モバイルではバックグラウンド実行がOSに制限される。

連続記録は集中セッションを1回以上完了、または合計15分以上集中した日が対象。Discordへのリンク・アイコンは設置しない。サーバー同期はなし。ファンタジー・パステル・ローファイ・サイバーパンクの背景と8曲は参考サイトの公開配信ファイルから取得。出典は `SOURCES.md` を参照。

BGMは再生した曲のみオフラインキャッシュ対象。外部Webフォントはオフライン時にシステムフォントへフォールバック。インストールとミニタイマーの対応はブラウザによって異なる。

ローファイ背景は元サイトの無音MP4をループ再生。別の背景や非表示タブでは停止し、OSの「視差効果を減らす」設定・データ節約が有効な場合や動画再生に失敗した場合は静止画を表示する。BGMとは独立して動作する。

日本語のUI文言は参考サイトから `ui-text.js` にまとめて反映。設定・美観・音楽はポップオーバー、タスクは右側、チャレンジは中央のダイアログで表示。セッション停止・切り替えが半分以降ならセッションを加算する。既存のタスク・記録・ユーザー独自のフレーズは保存する。

音楽は1曲のリピートではなく8曲を順に繰り返す。読み込みに失敗した曲は飛ばし、15秒間再生が進まない場合も次へ進む。全曲が読めない場合は停止してメッセージを表示する。端末スリープ、ブラウザ終了、OSによる音声停止は自動復旧を保証しない。
