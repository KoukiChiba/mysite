📖 バカラのルール（完全版）

  • 【目的】 プレイヤーとバンカーどちらが9に近いかを予想してベットする。自分でカードを操作することはできない。
  • 【カードの点数】 A=1点 / 2〜9=そのまま / 10・J・Q・K=0点。合計が10以上の場合は10を引いた1の位が得点（例：7+8=15 → 5点）
  • 【ナチュラル（Natural）】 最初の2枚の合計が8または9の場合「ナチュラル」と呼ばれ、そのラウンドは即終了。追加カードは引かれない。9はナチュラル9（最強）、8はナチュラル8。
  • 【プレイヤーの第3カード】 プレイヤーの合計が0〜5 → 必ず1枚引く / 6・7 → スタンド（引かない）/ 8・9 → ナチュラルで終了
  • 【バンカーの第3カード（詳細ルール）】
    バンカー合計0〜2 → 必ず引く
    バンカー合計3 → プレイヤー3枚目が8以外なら引く
    バンカー合計4 → プレイヤー3枚目が2〜7なら引く
    バンカー合計5 → プレイヤー3枚目が4〜7なら引く
    バンカー合計6 → プレイヤー3枚目が6・7なら引く
    バンカー合計7 → スタンド（引かない）
    ※プレイヤーが3枚目を引かなかった場合、バンカーは合計0〜5なら引く
  • 【配当】 プレイヤー勝ち: 1:1 / バンカー勝ち: 0.95:1（5%コミッション）/ タイ: 8:1
  • 【タイ（引き分け）について】 タイの場合、プレイヤー・バンカーへの賭けは引き分け扱いで返金される。タイに直接ベットしていた場合は8:1の配当。
  • 【マカオでの慣習】 マカオの本場ではバンカーが圧倒的に多く選ばれる。長期的にはバンカーの方が僅かに有利（ハウスエッジ: プレイヤー1.24%、バンカー1.06%、タイ14.36%）
  • 【おすすめの戦略】 初心者はバンカーに賭け続けるのが最もシンプルで勝率が高い。タイは高配当だが期待値が低いため控えめに。
